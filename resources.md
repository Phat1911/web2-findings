# Resources I actually use

## Practice
- [PortSwigger Web Security Academy](https://portswigger.net/web-security) — the core
- [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) — weekend reps
- [HackTheBox](https://www.hackthebox.com/) — University CTF (Dec) + optional boxes
- [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) — Linux floor, only if shaky

## Reference
- [OWASP Top 10 (2021)](https://owasp.org/Top10/)
- [OWASP API Security Top 10](https://owasp.org/API-Security/)
- [OWASP WSTG](https://owasp.org/www-project-web-security-testing-guide/) — skim methodology
- [MDN HTTP](https://developer.mozilla.org/en-US/docs/Web/HTTP) — when a header confuses me
